## 合并中修复的问题

真实浏览器发现：O1 控制器已写入指针坐标，但 W1 关闭按钮的 Hover 背景简写把 O1 `background-image` 清空。为窗口图标按钮补上精确作用域的选择器，只提高这层高光的优先级，保留原底色和关闭操作。没有新增业务状态、持久化、权限门禁或安全机制。

首次测试还有两个验证问题，均已修正：减少动画测试夹具错误地同时开启强制颜色；旧 Composer 测试仍要求闲置时常驻空引用说明。更新后同时验证 Drop 激活时说明仍可见，投递目标始终存在。

## 范围限制

这是本次 GUI 包的集成验证，不等同于全仓全部测试或正式发布。生产构建仍有既有的大体积资源提示；React Flow 有既有署名提示。服务启动时提示 agentlet daemon 缺失，本轮未验证语音识别及真实任务执行。

主工作区保存现有其他施工；上传分支以既有 GUI 分支提交为基础，仅加入本次包的生产改动及必要测试。两者共同改动的函数采用相同逻辑，主工作区的额外阅读与图集功能未被旧源文件覆盖。
