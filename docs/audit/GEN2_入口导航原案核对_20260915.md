# GEN2 入口导航原案核对

日期：2026-09-15
范围：核对 Figma 全设计包、`GEN2_UX框架总图与全旅程补漏_20260915.md` 与当前源码；本轮补入唯一 Locator 生产提示，不改领域/API，不提交。

## 先说结论

全局 Navigator / ColorPin / Railway 的视觉族和挂载方向已有明确原案，当前源码也有对应组件；本轮已补入唯一 camera/safeRect 下的生产可见 Locator cue。右侧“装备/沉浸预览悬浮栏”只能确认旧原始 Figma Frame，统一九面稿没有把它裁决为一个独立全局栏；当前实现是 route-level ProfessionalWindowStage、Assembly 入口和 Workflow 手牌的组合，仍需按产品决策补齐入口语义。

TemporalRail 有精确稿，但它是 Context child canvas 右侧的局部时间仪器，不能追认为全局装备栏。

## 当前已定、待核、未实现、未验证

### 已定

- ProjectShell route-level 只保留一套 Global HUD；Navigator、Railway、SurfaceDock、ProfessionalWindowStage 不作为第二套 Canvas 壳。
- Navigator 的 F 查当前对象位置、`Cmd/Ctrl+F` 搜未知对象、ColorPin 与画外 Locator 的形态要分开。
- Railway 是具体、可持续返回的目的地；底部三现场一级入口归 SurfaceDock。
- TemporalRail 只属于 Context child canvas 的右侧 local instrument。

### 待核

- 用户最新说的“右侧装备/沉浸预览悬浮栏”与旧 Figma `5046:66/67`、统一九面 `5388:27165` 之间的最终采用关系。
- Navigator 的跨现场 arrival 与 Locator overlay 在当前 production route 的真实 caller、safeRect 交互和返回焦点。
- Railway 的 Receive/reorder/hover preview/`+N` 组合规则与 Core 事务回执。

### 未实现

- 生产 ColorPin producer 与真实颜色组持久关系。
- Locator 的完整 travelling → arriving → hidden 状态证据、目标失效态与跨现场焦点恢复。
- Railway Receive、重排、溢出与真实 hover preview。
- 旧沉浸取材/装备 Frame 中的完整动作链尚未作为独立全局栏接入。

### 未验证

- 1440 以外的 Navigator/Railway/窗口避让组合。
- reduced-motion 下 Navigator hug、Locator 抵达回落、Railway/Temporal 动效。
- Reader/Assembly/装备从来源进入、关闭后恢复原对象与焦点的完整往返。

## 下一步（按最小范围）

1. 用户已经要求右侧呼出装备与沉浸预览，无需再确认这个目标。旧 `5046:66/67` 仅作为来源线索；其中“小精灵的装备/添加能力”不能直接等同工作流装备卡，需继续核对象语义和准确入口，不凭旧Frame发明常驻全局栏。
2. Locator cue 已落入生产挂载，下一步补它的真实 arrival/失效证据；随后补 ColorPin producer，再补 Railway Receive/reorder/preview，这些是跨入口共享链路。
3. 对 ProfessionalWindowStage 做一条真实往返：来源对象 → Reader/Assembly/Portal → 摘取或加入引用 → 关闭 → 回到来源并保留目标/焦点；将结果写入下一份浏览器验收记录。
