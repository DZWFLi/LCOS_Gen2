# T1 Text 承载节点物种接缝修复

2026-09-15。局部修复，不是整页视觉验收。未提交、未 push。

## 实际原因

真实浏览器已登记 3 个 Core Artifact binding，但节点都是 Huabu text 类型。NodeWrapper 只消费了 host presentation，TextNode 没有调用已有 body seam，导致绑定成功却显示 Type...。

TextNode 接缝补上后又实测到 body 高度为 0：原生 text 依赖自身内容测高，替换成物种 body 后不再运行原生编辑测量；当前节点只持久化宽度。

## 修改

- TextNode 分为薄 body 接缝和原 NativeTextNode。绑定时挂 NodeWrapper + 已注册物种 body；无 override 时保留完整原生编辑。没有新增按标题猜物种的判断。
- NodeWrapper 只在有 host presentation 且没有显式布局高度时，使用既有 measured/default nodeHeight 给 body 实际高度；显式高度不变，不写数据库或用户坐标。
- 保留当前所有未绑定节点，没有凭相似位置/标题删除所谓孤儿数据。
