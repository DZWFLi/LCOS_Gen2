# Portal 键鼠入口统一

## 本轮结果

修正真实入口冲突：LCOS 已替换 CanvasRef body，但原生 CanvasRef 的窗口级 Enter 监听和外层双击仍保留，可能跳到旧 `/canvas/:id` 路由。本轮将已被 host body 接管的节点原生导航停用，由 Portal body 打开同一目标预览。未接管的 Huabu 原生节点保持原行为。

前：LCOS Portal 双击 → 专业窗口预览；选中后 Enter → 可能跳旧画布路由。

后：LCOS Portal 双击 / 单选后 Enter → 同一个 typed canvas 目标预览；文本输入、多选、Composer 或专业窗口活动时不抢全局 Enter。

没有新增数据实体、数据库迁移或导航平台；复用现有 body seam、selection、shell openWindow 和真实预览。未提交、未推送，保留工作区其他改动。

## 对原卡的边界

本轮只修 P01/P02 的生产入口一致性。P03–P06 不能按完成登记。

导航审计见 `docs/audit/GEN2_导航复用精确落点_20260915.md`：当前缺 Context identity 到 child canvasId 的真实 producer、child enter caller、来源 camera/selection 恢复链、显式 return caller、move-end 到 navigation 的接线。现有三 Surface 切换不能冒充 child 路由。

下一步按原卡补真实目标映射，再接进入与返回；不得从 entityId 或标题猜画布，不得以关闭预览窗口冒充返回现场。

## 风险与回退

当前 CanvasRef 以 host body 是否接管为导航所有权边界；未来新增其他 CanvasRef host body 时，也需承接相应键盘入口。回退只撤销上述四文件中本轮局部补丁，不恢复或覆盖整个脏工作树。
