可以承诺的是这些区域的产品角色与操作边界已有依据，适合并行做外观。不能承诺整个页面零返工，因为窗口布局、真实子现场和跨区域动作仍在纠正，且浏览器实测未完成。

Chat 修改 CSS、token、视觉资产和呈现 props 时保留现有 handlers、目标身份、状态与异步结果判断；发现不符应在自己的交接中点名，不能把缺少功能藏掉或自造入口。与本地同时施工时按文件分工，先核当前工作树最新差异，不能覆盖本地 UX 修复。
