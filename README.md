# LCOS Gen2

**把资料拖进来，接着上次的创作继续做。**

LCOS 是正在开发的创作工作台，把素材、AI 对话和任务放在同一块画布上。界面设计围绕四个动作：

- **拖进去就能引用**：把资料拖进对话或提问，选清这次用什么、后续还要参考什么。
- **选中就能操作**：在素材旁边写要求、加引用、执行操作，少一些来回找按钮。
- **接着上次继续做**：延续已有对话，也能带着选定材料开始新对话。
- **看完回到原位置**：打开资料看细节，再回到刚才的任务，保留工作位置。

例如做产品视频：把客户资料、参考画面和脚本摆在一起，拖入需要的参考再向 AI 提问。第二天回来，找到原来的对话和材料，接着改。

## 当前进展

已完成界面方案和部分可实际操作的功能。完整资料整理、多窗口恢复和外部 AI 对话接续仍在开发。

## 为什么做这个

创作的麻烦往往发生在工具之间：找参考、补背景、追修改、接着昨天的任务做。LCOS 延续第一代“围绕一个项目持续工作”的思路，把重点放在拖放资料、就近操作和工作位置的保留上。

## 适合谁

经常需要参考图、文档、AI 对话一起工作的创作者，例如做广告策划、产品视频、设计提案的人。
